
# TrabajoTaller
Trabajo del taller sobre hacer un servidor en python. 
Diferencias entre GET, POST, PATCH y DELETE.
GET: Sirve para obtener datos sobre un programa, servidor en este caso.
POST: Sirve para crear nuevos datos, estos no se repiten.
PATCH: Sirve para modificar datos durante un tiempo determinado. 
DELETE: Sirve para eliminar datos de un servidor.
POST no es idempotente porque cada vez que se crea un recurso nuevo, este modifica el estado del servidor.
